## Release boundaries

- The original encrypted workspace remains owner-private and uses demonstration roles. The separate directory, connected text/file-homework/inbox, lesson/checkpoint and authored-practice, current-grade and attendance workflows use actual authenticated membership and assigned class/pupil scope. Those permissions do not yet cover the original profile, practice, AI, file registry and administration demos. No real pupils or guardians were enrolled.
- New records use the existing encrypted D1/R2 storage and audit mechanisms. No external messages or payments are sent by these flows.
- The update preserves earlier records. New school directories start empty; fictional directory examples appear only in anonymous preview. No migration deletes or replaces earlier work.
- Verification consists of 1,314 isolated workflow checks, TypeScript checking and the production build. Earlier desktop/phone browser reviews remain dated evidence; new v18 browser visual/interactive QA was unavailable in this run. External provider behavior, native camera hardware and official school readiness are not certified by these checks.
