# Reference feature scope — v21, 18 October 2026

All four supplied reference images were inspected and consolidated into **40 distinct capabilities**. The nine original concept modules remain. The updated 22-page PDF adds 13 catalogue areas, giving **62 entries**. The [complete page-level checklist](COMPLETE_SPECIFICATION_TRACEABILITY.md) tracks detailed role, behavior, AI, design and launch requirements. This accepts the entire product scope without claiming unfinished modules are working.

**Модули на Eduo** at `#modules` provides category/role/status/text filters, detail links, current/remaining explanations, valid links to available workspaces and filtered CSV. Filters grant no school permissions. Connected labels describe a working school-scoped part rather than full statutory completeness. Demos use fictional owner-private profiles; unfinished/provider/service entries show their requirements rather than fabricated records/actions.
